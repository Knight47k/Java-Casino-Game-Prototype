## 🚀 Getting Started

To begin contributing, you will need:
1. **Java Development Kit (JDK):** Version 11 or higher is recommended.
2. **IDE:** This project is designed to be compatible with **jGRASP** and **Visual Studio Code**.
3. **The Repository:** Fork this project and clone it to your local machine.
